# Games for fx-CG50 graphic calculator

Here you can find game files and installation instructions for your calculators. There are many more available online, and I only provided here those that I tested. 
It is important to notice that the calculators have very limited space, so if you want to install big games, you will have to delete others. 

# Before you start
While these games were tested to have no negative impact on a calculator, it is important to remind that we do not bear any responsibility for possible short term or long term problems with the usage of your fx-CG50 calculators. By downloading any files from this repository you accept full responsibility for your actions.

# Copying files
To get the files on the calculator you need to connect it with a mini-USB USB-A cable (that was given to you when you received the calculator) to your computer, and copy the files onto the device. It is very simple. 
# Native support
To play the following games you only need to copy the files on the device. File names are given in brackets:
- Blackjack (Blackjack.g3a)
- Doom (CGDoom.g3a AND doom.wad. Both files are required to load the game)
- Minecraft (minecraft-FX.g3a AND fxcraft folder. Both files are required to play the game)
- Minesweeper (minesweeperprizm19.g3a)
- Snake (Snake.g3a)
