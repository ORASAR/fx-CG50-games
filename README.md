# Games for fx-CG50 graphic calculator

Here you can find game files and installation instructions for your calculators. There are many more available online, and I only provided here those that I tested. 
It is important to notice that the calculators have very limited space, so if you want to install big games, you will have to delete others.

# Copying files
To get the files on the calculator you need to connect it with a mini-USB USB-A cable (that was given to you when you received the calculator) to your computer, and copy the files onto the device. It is very simple.

# Games for GameBoy
While there are a few games made for this calculator, there are not that many of them. 
You can play most GameBoy games as well, but with a few extra steps.

## Emulator
First you need to install GameBoy Emulator. Just copy [prizoop.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/prizoop.g3a) on the calculator. 
Then just copy a GameBoy game you want to play (.gb extension) on the calculator. 
To launch a GameBoy game on the calculator, open Prizoop app on the calculator and select the game. Press f6 and then shift.
